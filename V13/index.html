2. 클라우드 TTS (구글 음성으로 읽기)

🔊 듣기를 구글의 자연스러운 목소리로 읽습니다. 키가 없으면 휴대폰 음성으로 읽습니다. 한 번 만든 음성은 이 스마트폰(드라이브 연결 시 드라이브에도)에 저장되어, 같은 글을 다시 들을 때는 요금이 들지 않습니다.

1단계: Text-to-Speech 사용 설정하러 가기 ↗ 🔑 2단계: 클라우드 API 키 받으러 가기 ↗
3. 구글 드라이브 (스마트폰·PC 같이 쓰기)

연결하면 구글 드라이브 ‘음성 지시문’ 폴더에 앞에 붙는 문구, 메뉴별 저장한 지시문(V0, V1 …), 구글 음성으로 만든 음성 파일이 저장되어, 스마트폰과 PC 어디서 열어도 똑같이 보이고 다시 들을 때 요금이 들지 않습니다. 첫 화면의 ‘☁ 드라이브’를 눌러 연결합니다.
