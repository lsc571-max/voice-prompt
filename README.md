# 음성 지시문

항목별로 말하면 텍스트로 받아 적고, 하나의 지시문으로 합쳐 클로드에 보내는 앱입니다.

## 버전
- `V0/` — 첫 버전
- `V1/` — 세부 항목은 ‘진행 방식’에만(처음 5칸, ＋로 추가), 기본 항목 순서 고정, 자동 문구 3단계(전체 → 메뉴 → 세부 메뉴)
- `V2/` — ‘진행 방식’ → ‘진행 순서’로 이름 변경, 진행 순서를 누르면 별도 화면에 1·2·3·4·5와 ＋ 추가
- `V3/` — 1~5번 항목은 옆 마이크로 바로 말하고 글창에 표시, 진행 순서 칸마다 마이크·✕, 화살표 제거(길게 눌러 끌기만), 설정 칸마다 마이크, 전체 자동 문구에 전문가 역할 문구 추가
- `V4/` — 첫 화면 제목 옆 ⚙ 설정, 설정은 메뉴별 설정창(전체·앱 만들기·프로그램 만들기·검증하기·PC·웹·구글 연결), 자동 문구 전부 보이기, 구글 칸 마이크 제거, 항목마다 🗑 지우기, 저장 목록은 합친 지시문만(삭제·전체 삭제)
- `V5/` — 지시문 화면에서 ‘자동 문구 뒤에’ 버튼 제거 (버튼은 ‘자동 문구’ / ‘자동 문구 없음’, 자동 문구는 항상 앞에 붙음)
- `V6/` — 진행 순서 칸마다 🗑(말한 내용 지우기) 추가, 앱 만들기·프로그램 만들기·검증하기·PC·웹 화면 맨 위 자동 문구를 전부 펼쳐 보이고 그 자리에서 말하기·고치기·지우기 (상위 문구도 함께 표시)
- `V7/` — 구글 AI(Gemini): ‘AI로 한 번에 말하기’(항목별로 나눠 넣기), 진행 순서 ‘AI로 정리하기’, 지시문 ‘AI로 깔끔하게 정리’(되돌리기). 구글 연결은 숨김(설정 제목 5번 누르기), 키 받으러 가기 링크, 키는 스마트폰에만 저장
- `V8/` — ‘AI로 한 번에 말하기’를 그 자리 🎙로(말하고 다시 누르면 목적~전달할 내용·기타에 자동 배분), 다섯 입력칸 마이크 제거, ‘기타’ 항목 추가, 프로그램 만들기·검증하기에서 진행 순서 제거, PC·웹은 기타 다음에 진행 순서(안으로 들어감, ‘AI로 정리하기’ 🎙), 숨김 창에 Gemini·구글 음성 인식·클라우드 TTS·드라이브 각각 저장하기·테스트, 웹 작업에는 전체 자동 문구 안 붙음
- `V9/` — 전체 자동 문구는 첫 화면 맨 위로, 모든 문구는 접어 두었다가 누르면 펼쳐 그 자리에서 고치기·🎙, 앱 만들기 화면의 자동 문구 칸 제거(지시문에는 그대로 붙고 프로그램 만들기·검증하기 화면에서 고침), ⚙ 설정은 바로 구글 연결 창, 설정의 자동 문구 목록·5번 누르기 제거, 화면 글씨에서 동그라미 숫자 제거
- `V10/` — 모든 메뉴 화면은 ‘앞에 붙는 문구 (전체)’ + ‘앞에 붙는 문구 (메뉴 이름)’ 두 줄(앱 만들기 문구는 없애고 내용은 프로그램 만들기·검증하기 문구로 옮김), 웹 작업에도 전체 문구, ⚙ 설정은 빠르게 5번 눌러야 열림, 앱 이름(드라이브 폴더 이름)을 지시문을 보고 자동으로 짓기(구글 AI 키가 있으면 AI, 없으면 주제로)
- `V11/` — 첫 화면 ‘📄 만든 지시문 보기’(메뉴별 최근 합친 지시문·저장본 모아 보기, 🔊·열기·복사·클로드로), 지시문 상자·저장 목록에 작은 🔊 듣기(다시 누르면 멈춤)
- 수정할 때마다 원본은 그대로 두고 `V1/`, `V2/` … 새 폴더로 저장합니다.
- 루트 `index.html`은 항상 최신 버전으로 연결됩니다(공유 링크 자동 갱신).

## 기능
- 첫 화면: 전체 자동 문구(접기) / 앱 만들기 / PC에서 작업하기 / 웹으로 작업하기, 제목 옆 ⚙ 설정(빠르게 5번)
- 프로그램 만들기·검증하기: 다섯 항목 + 기타 (진행 순서 없음)
- PC 작업·웹 작업: 다섯 항목 + 기타 + 진행 순서(누르면 안으로, 칸마다 🎙·지우기·칸 삭제, 길게 눌러 끌어서 순서 변경)
- ✨ AI로 한 번에 말하기: 그 자리에서 🎙 → 다시 누르면 구글 AI가 항목·기타에 자동 배분 (되돌리기)
- ✨ AI로 정리하기(진행 순서): 🎙로 말하면 1, 2, 3 … 칸에 자동 배분 (되돌리기)
- 자동 문구: 각 화면 맨 위에 접혀 있고, 누르면 펼쳐서 그 자리에서 고치기·🎙 (모든 메뉴: 앞에 붙는 문구 (전체) + 앞에 붙는 문구 (메뉴 이름))
- 합치기(앞에 붙는 문구는 맨 앞, 또는 없음), 앱 이름 자동 짓기, 듣기, 편집, 복사, 클로드로 보내기, ✨ AI로 지시문 깔끔하게 정리(되돌리기)
- 만든 지시문 보기(첫 화면): 모든 메뉴의 최근 합친 지시문과 저장본을 한곳에서 🔊·열기·복사·클로드로
- 저장 목록: 합친 지시문만 V0, V1 … 으로 저장 (불러오기·텍스트 저장·복사·듣기·삭제, 전체 삭제)
- ⚙ 설정(빠르게 5번) = 구글 연결: Gemini·구글 음성 인식·클라우드 TTS·드라이브 — 키 받으러 가기, 저장하기, 테스트
- 키는 이 스마트폰(브라우저) 안에만 저장되며 화면에 다시 표시되지 않음
