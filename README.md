# 음성 지시문

항목별로 말하면 텍스트로 받아 적고, 하나의 지시문으로 합쳐 클로드에 보내는 앱입니다.

## 버전
- `V0/` — 첫 버전
- `V1/` — 세부 항목은 ‘진행 방식’에만(처음 5칸, ＋로 추가), 기본 항목 순서 고정, 자동 문구 3단계(전체 → 메뉴 → 세부 메뉴)
- `V2/` — ‘진행 방식’ → ‘진행 순서’로 이름 변경, 진행 순서를 누르면 별도 화면에 1·2·3·4·5와 ＋ 추가
- `V3/` — 1~5번 항목은 옆 마이크로 바로 말하고 글창에 표시, 진행 순서 칸마다 마이크·✕, 화살표 제거(길게 눌러 끌기만), 설정 칸마다 마이크, 전체 자동 문구에 전문가 역할 문구 추가
- `V4/` — 첫 화면 제목 옆 ⚙ 설정, 설정은 메뉴별 설정창(전체·앱 만들기·프로그램 만들기·검증하기·PC·웹·구글 연결), 자동 문구 전부 보이기, 구글 칸 마이크 제거, 항목마다 🗑 지우기, 저장 목록은 합친 지시문만(삭제·전체 삭제)
- `V5/` — 지시문 화면에서 ‘자동 문구 뒤에’ 버튼 제거 (버튼은 ‘자동 문구’ / ‘자동 문구 없음’, 자동 문구는 항상 앞에 붙음)
- 수정할 때마다 원본은 그대로 두고 `V1/`, `V2/` … 새 폴더로 저장합니다.
- 루트 `index.html`은 항상 최신 버전으로 연결됩니다(공유 링크 자동 갱신).

## 기능
- 첫 화면: 앱 만들기 / PC에서 작업하기 / 웹으로 작업하기
- 항목 6개(목적·주제·주의사항·활용하는 사람·전달할 내용·진행 순서), 번호·순서 고정. 1~5번은 항목 옆 🎙로 바로 말하기(글창에 표시), ‘진행 순서’를 누르면 1, 2, 3 … 순서 화면(칸마다 🎙, ＋ 추가, 길게 눌러 끌어서 순서 변경)
- 자동 문구: 설정 메뉴에서 전체 / 앱 만들기 / 프로그램 만들기 / 프로그램 검증하기 / PC / 웹 각각 설정
- 저장 목록: 합친 지시문만 V0, V1 … 으로 저장 (불러오기·텍스트 저장·복사·듣기·삭제, 전체 삭제)
- 녹음 + 받아쓰기(수정 없음), 녹음 파일과 텍스트 따로 저장
- 합치기(요약 없음), 자동 문구 넣기/없음(넣으면 맨 앞), 듣기(구글 TTS), 편집, 복사, 클로드로 보내기
- 구글 드라이브 저장: [앱 이름]/[작업]/[V번호] (설정에 OAuth 클라이언트 ID 입력 시)
- API 키는 기기 안에만 저장되며 화면에 다시 표시되지 않음
