더 안전하게 쓰려면 키를 받을 때 ‘API 제한’에서 해당 API만 허용해 두세요.
1. 구글 AI API 키 (Gemini)

‘AI로 한 번에 말하기’, ‘AI로 정리하기’, ‘AI로 지시문 정리’에 씁니다.

2. 구글 음성 인식 (Speech-to-Text)

휴대폰에 받아쓰기 기능이 없을 때만, 녹음한 말을 구글이 글자로 바꿔 줍니다. 보통은 없어도 됩니다.

1단계: Speech-to-Text 사용 설정하러 가기 ↗ 🔑 2단계: 클라우드 API 키 받으러 가기 ↗
3. 클라우드 TTS (구글 음성으로 읽기)

지시문 ‘듣기’를 구글의 자연스러운 목소리로 읽습니다. 키가 없으면 휴대폰 음성으로 읽습니다.

1단계: Text-to-Speech 사용 설정하러 가기 ↗ 🔑 2단계: 클라우드 API 키 받으러 가기 ↗
4. 구글 드라이브

넣으면 저장할 때 [앱 이름]/[작업]/[V번호] 폴더로 자동 저장합니다. 테스트를 누르면 구글 로그인 창이 뜹니다.

1단계: Google Drive API 사용 설정하러 가기 ↗ 🔑 2단계: OAuth 클라이언트 ID 받으러 가기 ↗
